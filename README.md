

# Tata Data Visualization (Forage) | Microsoft Excel Dashboard Project

An interactive **Microsoft Excel dashboard project** developed as part of the **Tata Data Visualization Virtual Experience Program (Forage)**.

This project analyzes **Bengaluru's EV Charging Network** using Excel's data analysis and visualization capabilities to generate business insights for charging demand, station utilization, customer behavior, and expansion strategy.

---

## Project Overview

The objective of this project was to transform raw operational data into interactive dashboards that support business decision-making.

The analysis focuses on:

* Charging demand trends over time
* Customer usage patterns
* Station utilization and operational efficiency
* ROI-driven expansion planning for new charging stations

---

## Tools Used

* Microsoft Excel
* Power Query
* Power Pivot
* Pivot Tables
* Pivot Charts
* Slicers
* DAX Measures

## Key KPIs

* 114,000 Charging Sessions
* 8,000 Active Customers
* 65 Charging Stations
* 2.9M kWh Energy Consumed
* ₹49.7M Total Revenue
* District-wise ROI & Demand-Supply Gap Analysis

---

## Business Insights

* Identified districts with the highest projected charging infrastructure gap.
* Compared ROI across Bengaluru districts to prioritize future investments.
* Analyzed customer behavior across different income tiers.
* Evaluated station utilization to identify high-demand locations.
* Connected energy consumption with revenue trends through interactive visualizations.
